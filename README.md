# fun-toys

子ども向けの「触って楽しい」「挙動で伝わる」体験をテーマにした  
Vueを用いた、インタラクティブWebアプリの個人制作です。

## Demo
https://playful-color.github.io/fun-toys/#/

※スマートフォン（特にiPhone）での操作を想定して実装しています。

---

## 概要

幼児〜小学生を対象に、遊び体験をテーマにした
Vue製のインタラクティブWebアプリです。

直感的な操作と視覚的フィードバックを重視した  
おもちゃ感覚のUI・インタラクションを実装しています。

- ぬり絵機能（Canvas）
- ボールを使ったインタラクション
- 色・音・動きのランダム要素

---

## UI / UX設計について

幼児と小学生では操作理解や反応速度が異なるため、  
年齢差を意識したUI・インタラクション設計を行っています。

- 幼児向け：  
  - 触るとすぐ音やボールが反応する・同時押しでも壊れない
  - 視覚的に分かりやすい変化を重視
- 小学生向け：  
  - 試行錯誤できる挙動
  - 押せそうで押せない、追いかけたくなる動きなど
    「遊び」が生まれる挙動を意識

### UX / インタラクション設計のポイント

- 説明を読まなくても操作できることを前提に、タップ・ドラッグ・視覚的な反応のみで完結
- 子どもが予想外の操作をすることを想定し、意図しない挙動も「遊び」として成立
- スマートフォンでの利用を重視し、DOMベースの実装からCanvas描画へ切り替え

## 設計意図（Composable・Storeによる責務分離と理由）

Fun Toysでは、**UI・描画・状態管理・初期化・アニメーションなどを明確に分離**することで、再利用性・保守性・拡張性を確保しています。

### Homeページ（塗り絵）

- **Home.vue**: UI統括・CanvasManagerとの橋渡し  
  → UI操作と描画を分離することで、CanvasManagerの描画ロジックをUIに依存させない
- **CanvasManager.vue**: Canvas描画・ブラシカーソル・キャラクター管理・タッチ操作統括  
  → 描画処理を統括し、UIと描画を疎結合に
- **usePainter.js**: 描画統合レイヤー  
  - useDrawing：描画操作（開始・中断・停止）  
  - useRendering：再描画処理（スケール・パン・再描画）  
  - useCoordinate：座標変換処理  
  → 描画関連の処理をComposable単位で分離することでテスト・拡張が容易
- **usePainterStore.js**: 状態管理（描画履歴・Undo/Redo・永続化）  
  → 複数Composableからの描画状態参照・更新を統一し、一貫性を保持
- **useBrushCursor.js**: ブラシカーソル管理  
  → UIと描画操作を切り離し、再利用可能に

### Aboutページ（ボールアニメーション）

- useBalls: ボール位置・速度・衝突判定  
- usePointer: 入力制御（マウス・タッチ）  
- useDemo: アニメーションシナリオ制御  
- useSound: 効果音制御  

> アニメーションロジックをUIから分離することで、再利用性とテスト性を向上

### Loadingコンポーネント

- useCanvasSetup: Canvas初期化・サイズ設定  
- useSvgDraw: SVGアニメーション描画  
- useEraser: 初期クリア・アニメーション制御  

> 描画前の準備とローディングUIを分離することで、再利用性と保守性を確保
